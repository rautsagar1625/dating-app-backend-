# Velvet — UX & Perceived Performance Guide

Engineering recommendations for launch-quality user experience.

---

## Optimistic UI Patterns

The golden rule: **never make users wait for a server roundtrip to see feedback.**

### Swipe (most critical interaction)

```typescript
// In your swipe handler (React Native)
const handleSwipe = useCallback(async (direction: 'like' | 'pass') => {
  const targetId = currentProfile.id;

  // 1. Animate immediately — don't await the API
  animateCardOut(direction);

  // 2. Advance the deck immediately
  setCurrentIndex(i => i + 1);

  // 3. Fire API in background
  try {
    const result = await api.swipe({ targetUserId: targetId, direction });
    if (result.matched) {
      // Show match celebration AFTER card has already left
      showMatchCelebration(result.match);
    }
  } catch {
    // Silent failure for swipes — log but don't disrupt flow
    // Retry queued locally for when connectivity restores
    pendingSwipes.current.push({ targetId, direction });
  }
}, [currentProfile]);
```

### Chat message send

```typescript
// Optimistic message — appears instantly
const sendMessage = (content: string) => {
  const tempId = `temp_${Date.now()}`;
  const optimisticMsg = {
    id:           tempId,
    content,
    status:       'sending' as const,
    createdAt:    new Date(),
    senderId:     currentUserId,
  };

  // Add to local state immediately
  setMessages(msgs => [...msgs, optimisticMsg]);

  // Socket emit
  socket.emit('send_message', { chatId, content, clientTempId: tempId });

  // Socket.IO ack → update status to 'sent'
  socket.once(`msg_ack:${tempId}`, () => {
    setMessages(msgs => msgs.map(m =>
      m.id === tempId ? { ...m, status: 'sent' } : m
    ));
  });

  // Timeout → show retry button after 10s
  setTimeout(() => {
    setMessages(msgs => msgs.map(m =>
      m.id === tempId && m.status === 'sending' ? { ...m, status: 'failed' } : m
    ));
  }, 10000);
};
```

## Skeleton Loading (never show empty state during load)

```typescript
// DiscoverFeed.tsx — show 3 card skeletons during initial load
{isLoading ? (
  <>
    <ProfileCardSkeleton />
    <ProfileCardSkeleton style={{ transform: [{ scale: 0.95 }] }} />
    <ProfileCardSkeleton style={{ transform: [{ scale: 0.90 }] }} />
  </>
) : (
  profiles.map(p => <ProfileCard key={p.id} profile={p} />)
)}
```

**ProfileCardSkeleton**: gradient shimmer animation via Reanimated `useSharedValue`. Matches exact dimensions of real card. Renders in < 16ms.

**Chat list**: skeleton rows while initial messages load. 8 rows, each with avatar circle + 2 text line placeholders.

**Rule**: never show a loading spinner where a skeleton is possible. Spinners feel like waiting; skeletons feel like loading.

## Image Loading Strategy

```typescript
// Use expo-image (not React Native Image) — disk + memory cache + blurhash
import { Image } from 'expo-image';

<Image
  source={{ uri: profile.photoUrl }}
  placeholder={profile.blurhash}      // already generated by your media pipeline
  contentFit="cover"
  transition={300}                    // 300ms crossfade from blur → sharp
  cachePolicy="memory-disk"           // cache aggressively
  recyclingKey={profile.id}           // re-use component instance on list recycle
/>
```

**Strategy**: load 480px medium variant first (fast, ~30KB) → 1080px large only when user taps/zooms.

**Prefetch**: preload next 3 profile images while user is viewing current:
```typescript
useEffect(() => {
  if (profiles[currentIndex + 1]) Image.prefetch(profiles[currentIndex + 1].photoUrl);
  if (profiles[currentIndex + 2]) Image.prefetch(profiles[currentIndex + 2].photoUrl);
  if (profiles[currentIndex + 3]) Image.prefetch(profiles[currentIndex + 3].photoUrl);
}, [currentIndex]);
```

## Feed Prefetching

```typescript
// Background feed refresh — users never hit an empty state
const PREFETCH_THRESHOLD = 5;  // start fetching when < 5 cards remain

const { data: feed } = useFeed();
const prefetchRef = useRef(false);

useEffect(() => {
  const remaining = feed.length - currentIndex;
  if (remaining < PREFETCH_THRESHOLD && !prefetchRef.current) {
    prefetchRef.current = true;
    fetchMoreProfiles().finally(() => { prefetchRef.current = false; });
  }
}, [currentIndex, feed.length]);
```

## Offline Handling

```typescript
// Queue swipes locally when offline, flush on reconnect
import NetInfo from '@react-native-community/netinfo';
import AsyncStorage from '@react-native-async-storage/async-storage';

const PENDING_SWIPES_KEY = '@velvet:pendingSwipes';

async function queueOfflineSwipe(targetId: string, direction: string) {
  const existing = JSON.parse(await AsyncStorage.getItem(PENDING_SWIPES_KEY) ?? '[]');
  await AsyncStorage.setItem(PENDING_SWIPES_KEY, JSON.stringify([...existing, { targetId, direction, ts: Date.now() }]));
}

async function flushPendingSwipes() {
  const pending = JSON.parse(await AsyncStorage.getItem(PENDING_SWIPES_KEY) ?? '[]');
  if (!pending.length) return;
  await Promise.allSettled(pending.map(s => api.swipe(s)));
  await AsyncStorage.removeItem(PENDING_SWIPES_KEY);
}

// Subscribe to network state — flush on reconnect
NetInfo.addEventListener(state => {
  if (state.isConnected) flushPendingSwipes();
});
```

**Offline toast**: non-blocking, appears at bottom of screen. Auto-dismisses when connectivity returns. Never blocks interaction.

## React Native Performance

### List rendering — use Flashlist
```typescript
import { FlashList } from '@shopify/flash-list';  // not FlatList

// Chat list (frequent re-renders)
<FlashList
  data={messages}
  renderItem={({ item }) => <MessageBubble message={item} />}
  estimatedItemSize={80}
  keyExtractor={m => m.id}
  inverted
/>
```
Flashlist uses RecyclerView on Android and UICollectionView on iOS. 5–10× faster than FlatList for long lists.

### Memo-ize stable components
```typescript
// ProfileCard receives stable props (profile object ref doesn't change during swipe session)
const ProfileCard = React.memo(({ profile, onSwipe }) => {
  // ...
}, (prev, next) => prev.profile.id === next.profile.id);
```

### Avoid useEffect waterfalls
```typescript
// Bad: sequential fetches
useEffect(() => { fetchProfile(userId).then(p => { fetchMatches(p.id).then(...) }) }, []);

// Good: parallel
useEffect(() => {
  Promise.all([fetchProfile(userId), fetchMatches(userId), fetchEntitlements(userId)])
    .then(([profile, matches, entitlements]) => setState({ profile, matches, entitlements }));
}, [userId]);
```

## Push Notification Timing

| Notification | Timing | Reason |
|-------------|--------|--------|
| New match | Immediately (< 5s) | High excitement — deliver at moment of match |
| "X liked you" (blurred) | 7pm local time | Highest open rate, don't spam throughout day |
| Re-engagement (idle 24h) | 9am local time | Next morning = natural app-opening moment |
| Payment receipt | Immediately | Transactional — always immediate |
| Chat message | Immediately (if offline) | Communication should never wait |
| Subscription expiring | 48h before | Enough time to act, not panic |

**Never send push notifications**: midnight to 8am local time. Use user's `lastKnownTimezone` from profile.

## Emotional Engagement Loops

### Match celebration (first impression matters)
- Duration: 1.5 seconds max (don't make users wait to navigate)
- Confetti or heart burst using Reanimated 2 — 60fps, no JS thread blocking
- "It's a Match!" title + both profile photos → fade in with scale animation
- CTA: "Send a Message" (primary) + "Keep Swiping" (secondary)
- **First match only**: full-screen modal. Subsequent matches: bottom sheet to reduce habituation.

### Super like differentiation
- Distinct card-throw animation (upward + blue glow) vs regular swipe
- Target user sees super like badge on your profile
- Sound effect option (haptic feedback always, audio only if user enabled)

### Streak engagement (day 5+)
```typescript
if (user.consecutiveDailyActiveDays >= 5 && !shownStreak.today) {
  showToast(`🔥 ${user.consecutiveDailyActiveDays}-day streak! Keep it up.`);
  setShownStreak({ today: true });
}
```

### Empty state (never say "no more profiles")
```
// Don't:
"No more profiles in your area."

// Do:
"You're all caught up! We're finding great new people for you.
 Come back tomorrow for fresh matches."
```
Show a friendly illustration + a prompt to adjust distance preferences or come back later.
